# 目标产品边界

当前仓库是逆向分析和接口证据归档，不是最终的小说搜索下载网页。最终产品在各平台达到可用证据边界后再进入实现阶段。

## 最终形态

- GitHub Pages 提供一个简易搜索、选择书籍、查看章节并发起下载的网页。
- GitHub Actions 构建并发布 Pages，同时构建 Linux、Windows 等 Rust 下载构件。
- 网页只展示已经达到可用边界的平台能力；未完成的平台保持明确的“未验证”状态。
- 番茄、抖音、起点分别保留独立目录、签名模块、接口报告和调用证据，不把不同平台的参数或算法混在一个实现里。

## 进入产品实现前的门槛

1. 番茄当前版本 Medusa 完成独立参数化，或明确取得可复现的匹配样本；随后完成无 JVM Rust 的注册、目录、正文和解密链路。
2. 番茄搜索获得非空 JSON，并记录真实请求字段和分页行为。
3. 抖音完成独立的当前版本线上请求和正文闭环。
4. 起点取得 APK、签名样本、接口矩阵和正文解密向量，完成独立验证。

在这些门槛完成前，Actions 只维护研究归档、检查和 Rust scaffold 构建，不把当前项目简介页包装成可用下载器。
