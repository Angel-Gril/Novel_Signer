# Qidian

This directory is intentionally an evidence-gap report. The isolated workspace contains no Qidian APK or native library, no signed Qidian request sample, no endpoint/parameter capture, no header-removal matrix, and no chapter decryption vector that can be attributed to Qidian.

Generic novel frameworks and unrelated `so-novel` material are not treated as Qidian reverse-engineering evidence. No Qidian algorithm or endpoint is claimed complete.

## Required evidence for a future analysis

1. Exact app/package and version;
2. one request/response capture with body, query, headers, and timestamp;
3. static request-construction and native-call traces;
4. one-variable server matrix;
5. content-key negotiation and plaintext hash from the same trial.
